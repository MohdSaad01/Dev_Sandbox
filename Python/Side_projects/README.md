# Python Projects 🐍

A collection of Python projects built while learning and applying Python concepts. The projects cover automation, games, GUI applications, web scraping, system utilities, and command-line programs.

## 📁 Projects

* **Cookie Clicker Bot** — A Selenium-based browser automation project that plays Cookie Clicker by automatically clicking cookies and purchasing available upgrades.

* **50 States Guessing Game** — A geography quiz built with Turtle graphics and CSV data where the player identifies all 50 U.S. states on a blank map.

* **Turtle Crossing** — An arcade-style game built with Turtle graphics where the player guides a turtle across a road while avoiding moving cars.

* **Virtual Coffee Machine** — A command-line program that simulates a coffee machine, including drink selection, payment, ingredient management, and resource tracking.

* **Classic Snake** — A Snake game built with Python's Turtle graphics, featuring movement, food collection, score tracking, and increasing difficulty.

* **FlashLang French** — A Tkinter flashcard application for learning French vocabulary through interactive cards and self-testing.

## 🛠️ Technologies

* Python
* Selenium
* Turtle
* Tkinter
* BeautifulSoup
* CSV
* psutil
* pandas

Each project is self-contained and can be run independently.
